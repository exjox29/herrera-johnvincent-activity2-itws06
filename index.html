Student Visual Hierarchy Documentation

Document the specific CSS strategies you implemented for at least 5 elements to establish visual hierarchy.

Target Element / Class Hierarchy Principles Applied Implementation Details & Design Rationale
.hero-title (h1) Size & Scale, Color & Contrast, Reading Patterns Made this the largest text on the page (2.75rem, bold) with high-contrast text color so it acts as the primary Level 1 focal point in a Z-pattern layout flow.
.brand-logo Size & Scale, Typography Hierarchy, Color & Contrast Used a larger and bold font to make the brand name noticeable in the header. Georgia was used to give the logo a distinct typographic style, while white text against the black header provides clear contrast.
.nav-cta Size & Scale, Color & Contrast, Proximity & Grouping Added padding and a red background to make the “Enroll Now” button stand out from the other navigation links. Its position with the other navigation items keeps it grouped with the main navigation.
.hero-description Typography Hierarchy, Negative Space, Reading Patterns Used a smaller font than the hero title and added line-height and bottom margin to make the paragraph easier to read. Its position below the main heading supports the natural top-to-bottom reading flow.
.card-grid Alignment & Grids, Proximity & Grouping, Negative Space Used a three-column grid to organize the three courses evenly. The gap between the cards separates each course while keeping them visually grouped as one section.
.course-card Proximity & Grouping, Negative Space, Color & Contrast Added padding to give the content enough space and used a black border to separate each card from the page background. Related information such as the category, title, description, course details, and link are kept together inside each card.
